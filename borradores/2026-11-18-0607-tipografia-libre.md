# Reel 2026-11-18-0607-tipografia-libre

- **Tema:** tipografías libres y de código abierto para la identidad de marca.
- **Fuente:** joshpuckett/allo, https://github.com/joshpuckett/allo (tendencia en GitHub; el README dice que es gratuita, de código abierto, variable en peso, redondez y tamaño óptico, pensada para pantallas, instalable con npm).
- **Por qué este tema:** las demás fuentes de la cola fueron de consumo o de riesgo (credenciales, registro de cuentas), así que se buscó una tendencia técnica con relación directa a diseño web y marca de JDT. Las búsquedas de noticias del día no dieron una nota concreta para pymes.
- **Concepto:** «Tu letra tiene perillas»: una marca no se compra hecha, se ajusta como una consola de sonido. La misma letra puede ser seria para una contadora y amable para una panadería.
- **Formato:** gancho absurdo, terminal que cambia la redondez, pantalla dividida (giro), consola de tres controles, la letra que viaja a web, app y tarjeta, cierre.
- **Producción:** motor HTML (html/2026-11-18-0607-tipografia-libre.html), 6 escenas, 25 s, voz de ElevenLabs.
- **Concepto creativo:** desarrollado por el modelo capaz (opus, porque fable no estaba disponible con créditos). Ideas descartadas: mito y realidad, cuestionario de personalidad, una persona con la misma letra en tres personalidades, la letra que se redondea con las emociones.
